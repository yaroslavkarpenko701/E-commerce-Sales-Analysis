# E-commerce-Sales-Analysis
E-commerce sales analysis using SQL, Python, and Tableau.

Project Objectives:
* to demonstrate skills in extracting data from a database using SQL;
* to demonstrate skills in exploratory and statistical analysis using Python;
* to demonstrate skills in building dashboards in Tableau.

This directory contains Jupyter Notebooks with data extraction, data preparation, exploratory data analysis, and statistical analysis.
